[Logic Analysis]
- ['config.py', 'Contains all experiment hyperparameters and configuration settings (e.g., evaluation budget, learning rates, network architecture parameters, random seed settings). This file is imported by all other modules to ensure consistent configuration.']
- ['utils.py', 'Provides general utility functions such as random seed initialization, logging functions, Sobol sequence generation for initial samples, and helper methods for tensor manipulation. Both the training loop and evaluation modules use these utilities.']
- ['benchmark.py', 'Defines the Benchmark class which encapsulates synthetic and real-world problem definitions. Implements methods for evaluating a candidate design (returning objective value and feasibility flag) and generating initial samples (using Sobol sequences). This module is a dependency for the BOTrainer.']
- ['gp_surrogate.py', 'Implements the GPSurrogate class using BoTorch/GPyTorch. Contains methods to update the GP model with feasible objective data, predict mean and variance at candidate points, and compute the Expected Improvement acquisition value at a given x. This module imports configuration from config.py and utilities from utils.py.']
- ['deep_ensemble.py', 'Implements the DeepEnsembleClassifier class using PyTorch. Consists of an ensemble of MLPs (with configurable number of layers and neurons) trained using an ELBO loss for variational inference. Exposes methods for training on labeled constraint data and for predicting feasibility probability along with its uncertainty (to be used for dynamic boundary calculation).']
- ['acquisition.py', "Implements the AcquisitionOptimizer class. Uses the GP acquisition function (e.g., EI) and the dynamic constraint from the deep ensemble to perform constrained optimization. Includes a pre-optimization step with Adam to drive candidates towards the constraint boundary, followed by SciPy's SLSQP for final refinement. This module bridges the output of GPSurrogate and DeepEnsembleClassifier to propose new candidate points."]
- ['botrainer.py', 'Implements the BOTrainer class which orchestrates the Bayesian optimization loop. It integrates Benchmark, GPSurrogate, DeepEnsembleClassifier, and AcquisitionOptimizer. In each iteration, it updates the surrogate models, optimizes the acquisition function under the dynamic bound constraint, and logs the evaluation results. This class holds the main training loop and dataset updates.']
- ['evaluation.py', 'Defines the Evaluation class to compute metrics such as the best objective value achieved, feasibility ratio, and constraint classifier accuracy (e.g., using Balanced Accuracy). This module is called after training to analyze the performance over iterations.']
- ['main.py', 'Serves as the entry point of the application. Loads configuration from config.py, initializes all modules (Benchmark, GPSurrogate, DeepEnsembleClassifier, AcquisitionOptimizer, BOTrainer), and triggers the BO loop by calling BOTrainer.run(). After training, it calls the Evaluation module to compute and log final metrics.']

[Shared Knowledge]
All modules share configuration settings defined in config.py. The training data structure (e.g., a list/dictionary of (x, objective) for GP and (x, feasibility) for classifier) is maintained by BOTrainer and passed to both GPSurrogate and DeepEnsembleClassifier. Utility functions in utils.py are used across modules for random seed setting, logging, and Sobol sequence generation. Consistent tensor data types and device settings (CPU/GPU) should be maintained across all modules.
