──────────────────────────────
1. OVERVIEW OF THE METHODOLOGY

• The goal is to solve a black‐box objective minimization problem in the presence of unknown (binary) constraints.  
• Two surrogate models are used:
  – A Gaussian Process (GP) based surrogate (using BoTorch) for modeling the expensive objective function.
  – A deep ensemble of Multi-Layer Perceptron (MLP) classifiers for modeling the constraint (feasible vs. infeasible).  
• The key insight is that in many physical systems the optimum lies at the boundary between feasible and infeasible domains. To efficiently find the optimum, the method actively steers the sampling toward the constraint boundary by using a dynamic bound strategy.

──────────────────────────────
2. METHODOLOGY DETAILS AND ALGORITHM DESIGN

A. Bayesian Optimization Setup  
 • Begin with an initial set of design points (e.g., drawn from a Sobol sequence) to “seed” the process.  
 • In each BO iteration:  
  – Update both surrogates with the new observations.  
  – Use the GP surrogate to compute an acquisition function (the paper uses Expected Improvement, EI).  
  – Use the deep ensemble classifier to “gate” candidate points by ensuring they lie near the boundary.

B. Constraint Modeling with Deep Ensembles  
 • Architecture Details:  
  – Use an ensemble (default: 5 members) of MLPs.  
  – Each MLP has 4 fully connected layers with ReLU activations.  
  – Hidden layer size: Use 64 × floor(log₂(d)) neurons per hidden layer, where d is the dimensionality of the problem.
 • Training Details:  
  – Train each network via variational inference (using the evidence lower bound, ELBO) rather than maximum likelihood estimation. This is crucial to obtain well-calibrated uncertainties.
  – Use the Adam optimizer with a learning rate of 3e‑4 and train for 1,000 iterations per update.
  – Do not use dropout/regularization (follow recommendations from Lakshminarayanan et al. 2017).
 • Output Transformation and Uncertainty Estimation:  
  – Each ensemble member outputs a latent value g(x).  
  – Convert the latent value to a probability using the standard normal CDF (Φ), so the predicted feasibility is C(x) = Φ(µg(x) ± uncertainty).  
  – For a given input x, compute the ensemble’s mean (µ_E) and uncertainty (σ_E). In practice, compute σ_E as half the difference of the transformed confidence interval [Φ(µg – σg), Φ(µg + σg)].
  – This uncertainty metric is later used to define a dynamic bound.

C. Dynamic Boundary Exploration  
 • The idea is to force the optimizer to sample near the “boundary” between feasible and infeasible regions.  
 • Define a dynamic lower bound for the constraint classifier:  
  – l(x) = 0.5 – σ_E(x)             (σ_E is the standard deviation computed via the ensemble)  
  – Upper bound is fixed as u(x) = 1.  
 • When optimizing the acquisition function, the candidate x must satisfy:  
  l(x) ≤ C(x) ≤ u(x)  
 • Use a two-step approach for acquisition optimization:  
  – First, use a gradient-based Adam optimizer to “nudge” an initial random candidate toward satisfying the constraint (i.e., so that its feasibility probability is close to 0.5).  
  – Then, refine the candidate using a constrained optimizer such as SLSQP (from SciPy) that can handle the nonlinear inequality constraint.

D. Acquisition Function and Newton Iteration  
 • Use the Expected Improvement (EI) acquisition function computed from the GP surrogate.  
 • Note: Although EI is used in the paper, the formulation is generic so that other acquisition functions (e.g., UCB) can be substituted if desired.
 • The constrained acquisition optimization becomes:  
  maximize q(x) = EI(x)  
  subject to l(x) ≤ C(x) ≤ 1  
 • The constraint “pushing” effect is achieved because the method encourages sampling in regions where C(x) is just above the lower bound, i.e. near the boundary.

E. Iterative BO Loop  
 • At every iteration, perform the following steps:
  1. Update the GP surrogate for the objective using the currently available feasible evaluations.
  2. Update or retrain the deep ensemble classifier using all evaluations (feasible evaluations carry objective values; infeasible evaluations are flagged only with a binary label of 0).
  3. Compute or re‐optimize the dynamic bound l(x) = 0.5 – σ_E(x) across x.
  4. Solve the constrained acquisition optimization problem to propose the next candidate for evaluation.
  5. Evaluate the candidate:
   – If the candidate is feasible, obtain its objective value.
   – If it falls in the infeasible region, mark it and update the classifier accordingly.
 • Continue until the evaluation budget (e.g., 200 evaluations) is exhausted.

3. EXPERIMENTAL SETTINGS AND DESIGN

A. Benchmark Test Problems  
 • Synthetic functions:  
  – Townsend (2D)  
  – Simionescu (2D)  
  – LSQ (2D)  
 • Real-world design problems (with varying dimensions):  
  – Three-Bar Truss Design (2D)  
  – Tension-Compression String Design (3D)  
  – Welded Beam Design (4D)  
  – Gas Transmission Compressor Design (4D)  
  – Pressure Vessel Design (4D)  
  – Speed Reducer Design (7D)  
  – Planetary Gear Train Design (9D)  
  – Rolling Element Bearing Design (10D)  
  – Cantilever Beam Design (30D)  
 • Note: Ensure that for each test problem you correctly encode the objective function and its (hidden) binary constraints. The constraints are provided in the paper—but in our implementation, only their outcome (feasible = 1, infeasible = 0) is used.

B. Experiment Configuration & Data Generation  
 • For each problem, generate the initial design points using a scrambled quasi-random Sobol sequence.  
  – Example: 10 initial samples per run (or 20 for comparable experiments with SVM-CBO as noted in the paper).  
 • Total evaluation budget: 200 evaluations per run.  
 • Run experiments using 10 independent random seeds—ensure that all algorithms share the same initial sample set for fair comparison.
 • For baseline comparison, plan to implement (or wrap readily available implementations for):
  – CEI (Constraint Expected Improvement)  
  – SCBO  
  – SVM-CBO (using the original code framework if available)  
  – Random Search  

C. Hyperparameters  
 • GP for objective:
  – Kernel: Matern 5/2 (with default hyperparameters from BoTorch).  
 • Deep Ensemble for constraint surrogate:
  – Network architecture: 4 fully connected layers with ReLU, 64×floor(log₂(d)) neurons per layer.  
  – Ensemble size: 5 (with experiments showing insensitivity to ensemble size between 3 and 8).  
  – Learning rate: 3e‑4  
  – Number of training iterations: 1,000  
  – Loss: Variational Inference via the ELBO (instead of binary cross-entropy)  
 • Acquisition optimization:
  – Use Adam to generate constraint-satisfying initial candidates; then refine using SciPy’s SLSQP.
  – Tolerance and maximum iterations for SLSQP to be determined empirically.

D. Evaluation Metrics  
 • Track the best (minimum) objective value found over iterations (f′) as a function of the number of function evaluations.  
 • Plot learning curves (mean ± standard deviation over 10 runs).
 • Feasibility Ratio: Monitor the number of feasible versus infeasible samples over iterations.  
 • (For diagnostic purposes) Measure the Balanced Accuracy of the constraint classifier using true feasible/infeasible labels.
 • Runtime measurements: Record the time per BO iteration and overall runtime (as shown in the paper’s runtime comparisons).

  3. deep_ensemble.py  
   – Implementation of the deep ensemble of MLP classifiers.  
   – Include functions for network definition, training loop (with ELBO loss), prediction (mean and variance), and transformation to probability using the standard normal CDF.
  4. acquisition.py  
   – Implementation of the EI acquisition function and its constrained optimization routine.
