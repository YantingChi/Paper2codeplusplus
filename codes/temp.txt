[Planning] Overall plan
============================================
Below is a detailed roadmap that covers both the reproduction of the methodology (how TyPro works internally) and the experimental evaluation (datasets, settings, and metrics). This plan is designed to guide you through constructing your own prototype based solely on the paper’s description.

──────────────────────────────
1. Overall Project Structure
──────────────────────────────
• Environment Setup  
  – Base your work on a fixed version of Clang/LLVM (the paper uses LLVM 10).  
  – Install and integrate a datalog solver such as Soufflé.  
  – Set up a build system so that individual source files’ fact outputs can be merged at link time.  
  – Prepare to compile and run on multiple architectures (x86_64, ARM, and if possible MIPS) or use emulators (e.g., QEMU) for ARM/MIPS testing.

• Repository & Modularity  
  – Partition the project into components: AST Fact Extraction, Datalog-based Analysis, Code Transformation (rewriting indirect calls), Runtime Library for dynamic linking support, and Evaluation harness (for benchmarks and test suites).

──────────────────────────────
2. Methodology Reproduction
──────────────────────────────
A. Fact Extraction from the Clang AST  
  • Modify Clang’s front-end so that when parsing C code, it traverses the AST and extracts the following “facts”:  
   – Type and Context Pairs:  
     ○ For every expression in a function, capture a pair (type, context) and assign a unique identifier. (E.g., TypeContextPair(n, t, c)).  
    ○ Also record global variables (as context) and function declarations (return and parameter types).  
  • Type Constructs:  
   – For pointer types, extract and store the pointee type (via a PointsTo relation).  
   – For compound types like structures and unions, record fields using relations such as StructMember (with byte offset) and UnionMember (with field type).  
  • Casts & Transfers:  
   – For every cast (explicit or implicit), record a fact in the form Cast(n_src, n_dest) indicating type propagation across casts.  
   – This should cover casts between function pointer types as well as propagations happening as parameters are passed into functions or from indirect call arguments (and return types, if used).

  • Function Pointers & Indirect Calls:  
   – Identify all “address-taken” functions by detecting expressions such as &f outside direct calls. Create facts like FunctionPointer(n, f, num_args, is_vararg).  
   – For every indirect call (e.g., e′(a1, …, am)), record ICall(N(e′), call_expression, m) along with a separate TypeCall fact that records the type expected (but note that for indirect calls the context may be approximated).  

B. Fact Aggregation and Optimizations  
  • Merge all fact sets coming from different compilation units (source files).  
  • Implement optimizations such as:  
   – Omit TypeContextPair facts that are not referenced in any other relation (to reduce the size of the fact base).  
   – Skip primitive C types (e.g., char, void) that are not relevant for function pointer propagation.  
   – Collapse chains of direct casts as described (e.g. handling “(fptr_int)((void*)&f1)” as one direct cast).  
   – Merge equivalent type/context pairs when reciprocal Cast facts exist (as outlined in the optimizations section).

C. Datalog Analysis (Type Propagation & Target Set Computation)  
  • Encode the propagation rules as Horn clauses in the datalog language. The key groups of rules are:
   1. Propagation rules:  
    – Rule (T): Transitive propagation across multiple casts.  
    – Rule (P): Pointer aliasing (bidirectional propagation when pointers get cast).  
    – Rules (S) and (U): Propagate types through structure and union fields.
   2. Target Set rules:  
    – Rule (F1) for fixed-arity functions and rule (F2) for variadic functions. These rules use the computed Cast relation to “connect” the type of an indirect call site with function pointer types that have the correct arg-count.  
   3. Indirect call context transfer (IC1 and IC2):  
    – To cover cases where the arguments’ or return types’ contexts matter, add rules that simulate context transfer from the caller to the potential callee.
  • Feed the merged and optimized fact set into Soufflé along with your Horn clause rules.  
  • Run the solver until no new facts in the TargetSet(n_call, f) relation are derived. This final relation represents the allowed function targets for every indirect call.

D. Code Transformation & Enforcement  
  • Instrument the LLVM code-generation phase:  
   – Modify or add a pass that replaces every indirect function call with a switch-case construct.
   – Each case in the switch corresponds to one valid target (as computed in the TargetSet relation) and makes a direct call using the function’s unique identifier.
   – In the default case (i.e., if the identifier does not match any target), insert code to terminate the program immediately.
  • For address-taken functions, replace function pointers in memory with a unique function identifier.  
  • Ensure that your transformation yields a binary that enforces the forward CFI policy without runtime overhead (apart from the negligible cost from the switch-case structure).

E. Dynamic Linking Support (Advanced Component)  
  • Implement module summary generation:  
   – For each module, export the “external” facts (those that might be visible across module boundaries) using additional relations (ExternalSymbol, InterfaceType, etc.) as described in the paper’s Appendix B.  
  • At runtime, build a runtime library (in C++) that loads these module summaries and re-runs the target set computation if new modules are loaded.  
  • Use just-in-time techniques to recompile new switch-case constructs when the target sets expand due to dynamic loading.  
  • (NOTE: The precise integration of the summary and JIT compilation may require further design iterations as the paper’s description is high level; document your assumptions as you implement.)

Below is an annotated version of what the rules.dl file might look like. In this file we formally capture (using Horn clauses) the key propagation rules described in the paper. These rules cover transitive casts, pointer aliasing, struct/union field propagation, and finally the derivation of allowed targets for an indirect call using fixed‐ and variadic‐arity checks as well as “context transfer” rules. Note that the names of the relations exactly match the facts produced during AST extraction (e.g., TypeContextPair, PointsTo, StructMember, UnionMember, Cast, ICall, FunctionPointer, and (optionally) TypeCall). Also note that some rules (IC1 and IC2 below) are a simplified approximation for the “indirect call context transfer” part of the analysis. Adjustments may be needed when integrating with the rest of the pipeline.

------------------------------------------------------------
/* rules.dl – Datalog rules for type propagation and target set computation */
/* 
   Relation Declarations.
   These facts (and their attributes) are expected to be extracted by the ASTExtractor
   and then optimized by FactOptimizer. Their names and signatures are fixed.
*/

.decl TypeContextPair(id: number, type: symbol, context: symbol)
.decl PointsTo(ptr: number, pointee: number)
.decl StructMember(parent: number, member: number, offset: number)
.decl UnionMember(parent: number, member: number, fieldType: symbol)
.decl Cast(src: number, dst: number)         // Direct casts and transfers (from explicit casts, implicit transfers, etc.)
.decl ICall(callType: number, callLabel: symbol, arity: number)
.decl FunctionPointer(id: number, func: symbol, arity: number, vararg: bool)
/* Optional: For handling argument/return type transfers for indirect calls */
.decl TypeCall(id: number, type: symbol, callLabel: symbol)

/* The final result: mapping each indirect call (by label) to allowed function targets. */
.decl TargetSet(callLabel: symbol, func: symbol)

/* ===========================================================================
   Rule Group 1: Cast Propagation 
   ---------------------------------------------------------------------------
   (T) Transitive propagation: if X casts to Y and Y casts to Z then X casts to Z.
============================================================================ */
Cast(X, Z) :- Cast(X, Y), Cast(Y, Z).

/* ===========================================================================
   Rule Group 2: Pointer Aliasing Propagation 
   ---------------------------------------------------------------------------
   (P) If a cast propagates between two pointer types, then the cast applies
       to the pointee types as well. We derive two symmetric rules.
============================================================================ */
Cast(Xp, Yp) :-
    Cast(X, Y),
    PointsTo(X, Xp),
    PointsTo(Y, Yp).

Cast(Yp, Xp) :-
    Cast(Y, X),
    PointsTo(Y, Yp),
    PointsTo(X, Xp).

/* ===========================================================================
   Rule Group 3: Struct and Union Propagation 
   ---------------------------------------------------------------------------
   (S) For structures: If two struct types are related via a cast, then their
       corresponding fields (identified by matching byte offset) also propagate.
============================================================================ */
Cast(Member1, Member2) :-
    Cast(Struct1, Struct2),
    StructMember(Struct1, Member1, Off),
    StructMember(Struct2, Member2, Off).

/* ---------------------------------------------------------------------------
   (U) For unions: When propagating unions, the field transfer is allowed only
       if the field types match (using the field type for comparison).
============================================================================ */
Cast(Member1, Member2) :-
    Cast(Union1, Union2),
    UnionMember(Union1, Member1, FieldType),
    UnionMember(Union2, Member2, FieldType).

/* ===========================================================================
   Rule Group 4: Target Set Computation
   ---------------------------------------------------------------------------
   Rules F1/F2 compute the TargetSet relation by “connecting” an indirect call
   (its expected type, number of arguments) with an address-taken function
   (recorded in a FunctionPointer fact), provided a valid cast propagation exists.
============================================================================ */

/* (F1) For fixed-arity functions: 
   An indirect call with arity A can target a function pointer with exactly A parameters,
   provided that the type used in the indirect call (callType) propagates (via Cast)
   to the type associated with the function pointer.
*/
TargetSet(Call, f) :-
    ICall(CallType, Call, A),
    FunctionPointer(fp, f, A, false),
    Cast(CallType, fp).

/* (F2) For functions that accept a variable number of arguments:
   Even if the arity is marked as variadic (vararg true), a similar rule applies.
*/
TargetSet(Call, f) :-
    ICall(CallType, Call, A),
    FunctionPointer(fp, f, A, true),
    Cast(CallType, fp).

/* ===========================================================================
   Rule Group 5: Indirect Call Context Transfer
   ---------------------------------------------------------------------------
   These rules (IC1 and IC2) are designed to capture the transfer of type context
   from an indirect call’s argument or return type to that of the callee function.
   They help “simulate” a direct call by aligning the call context with the function’s.
   (Note: The following are heuristic approximations and assume that a corresponding
   TypeCall fact is generated during AST fact extraction.)
============================================================================ */
 
/* (IC1) For call argument types:
   If an indirect call call (by label) has an argument type (as a TypeCall fact) and if,
   in a candidate function f, a corresponding parameter appears (recorded via a TypeContextPair),
   then we derive an additional cast propagation between these type/context pairs.
*/
Cast(TCall, TFunc) :-
    TargetSet(Call, f),
    TypeCall(TCall, ArgType, Call),
    TypeContextPair(TFunc, ArgType, f).

/* (IC2) For return types:
   Similarly, if an indirect call expects a return type (captured by a TypeCall fact)
   and the target function f provides a return type (recorded in TypeContextPair),
   a cast is derived. 
*/
Cast(RetCall, RetFunc) :-
    TargetSet(Call, f),
    TypeCall(RetCall, RetType, Call),
    TypeContextPair(RetFunc, RetType, f).

/* ===========================================================================
   (Optional) Optimization Rule: Fact Equivalence
   ---------------------------------------------------------------------------
   When two TypeContextPair facts are found to be mutually casting (i.e., X casts to Y
   and Y casts to X), they are considered equivalent. This information can be used
   by the FactOptimizer to merge duplicate identifiers.
============================================================================ */
.decl Equivalent(id1: number, id2: number)
Equivalent(X, Y) :- Cast(X, Y), Cast(Y, X), X < Y.

/* ===========================================================================
   Additional External Rules for Dynamic Linking (if needed)
   ---------------------------------------------------------------------------
   Based on Appendix B in the paper, additional rules would mark certain type/context
   pairs as ‘external’ when they appear in module summaries. These rules are not fully

 a. TypeContextPair Merging
  – Check for reciprocal Cast facts. If there is a Cast fact from fact A to fact B (i.e., Cast(A, B)) and also a Cast fact Cast(B, A), then the two TypeContextPair facts underlying A and B are equivalent and can be merged.
  – Choose a canonical representative (for example, the one with the lower id) to represent the merged pair.
  – Update all other facts that refer to the non-canonical id so that they now reference the canonical id.
 b. Duplicate Facts
  – For any two facts that are identical (same fact_type and same data), remove duplicates so that only one instance remains.

──────────────────────────────

 a. Build a directed “cast graph” where each node is a fact id (typically from a TypeContextPair) and each edge represents a Cast fact (edge from “src” to “dest”).

   – For each allowed target from the target_sets mapping, add a case branch.

   – In each allowed-target block, emit a direct call instruction.

    • Pass the original call arguments.
    • Ensure that the calling convention and return type are preserved.
   – End each allowed-target block by branching to a common continuation block (or by directly returning the result if no further control flow is required).

   – This block will be executed if the switch does not match any allowed function ID.  
   – In this block, call a predefined error handler (for example, a function like __typro_fail) that terminates the program immediately.  
   – This default branch implements the enforcement: if an attacker attempts to hijack the call, the default branch prevents arbitrary code execution.

  1. Redirect the control flow:
   – Insert an unconditional branch from the original block (where the indirect call was located) to the new switch block.
   – Ensure that after the direct call cases, control returns to the same continuation that would have followed the original call.  
  2. Preserve debug and metadata information where applicable.

F. Order the Cases  
  1. To aid later LLVM optimization (e.g., jumptable generation), order the case values in ascending numeric order.  
  2. This ordering may help reduce binary size overhead and improve branch prediction at runtime.

/* ===========================================================================
   Rule Group 1: Cast Propagation (Transitivity)
   If a cast exists from X to Y and from Y to Z then we conclude a cast from X to Z.
============================================================================ */
Cast(X, Z) :- Cast(X, Y), Cast(Y, Z).

/* ===========================================================================
   Rule Group 2: Pointer Aliasing Propagation
   Propagate casts through pointer aliasing.
   If a cast exists between two pointer types then the cast applies to their pointee types.
============================================================================ */
Cast(Xp, Yp) :-
    Cast(X, Y),
    PointsTo(X, Xp),
    PointsTo(Y, Yp).

Cast(Yp, Xp) :-
    Cast(Y, X),
    PointsTo(Y, Yp),
    PointsTo(X, Xp).

/* ===========================================================================
   Rule Group 3: Struct and Union Propagation
   Propagate casts within compound types (structures and unions).
============================================================================ */

/* (S) Struct propagation:
   For two structures related by a cast, if they have a member at the same offset,
   then propagate the cast to the corresponding members.
*/
Cast(Member1, Member2) :-
    Cast(Struct1, Struct2),
    StructMember(Struct1, Member1, Off),
    StructMember(Struct2, Member2, Off).

/* (U) Union propagation:
   For unions, propagate only when the field type matches exactly.
*/
Cast(Member1, Member2) :-
    Cast(Union1, Union2),
    UnionMember(Union1, Member1, FieldType),
    UnionMember(Union2, Member2, FieldType).

/* ===========================================================================
   Rule Group 4: Target Set Computation
   Compute the allowed targets for an indirect call by matching expected call type 
   with function pointer types that are valid according to the cast propagation.
============================================================================ */

/* (F1) For fixed-arity functions:
   An indirect call with arity A may target a function pointer with exactly A parameters 
   (vararg flag false) provided that the cast from the call’s type to the function pointer’s 
   type exists.
*/
TargetSet(Call, f) :-
    ICall(CallType, Call, A),
    FunctionPointer(fp, f, A, false),
    Cast(CallType, fp).

/* (F2) For variadic functions:

TargetSet(Call, f) :-

        self.type_context_map: Dict[Tuple[str, str], int] = {}
        self.next_id: int = 0

        # Load configuration from config.yaml

        # Use compile flags from configuration; setting "-std=c99" and optimization flag from config.
        optimization: str = config.get("build", {}).get("optimization", "-O3")
        self.compile_args: List[str] = ["-std=c99", optimization]

        self.logger: logging.Logger = get_logger("ASTExtractor")

    def extract_facts(self, source_dir: str) -> List[Fact]:
        """
        Traverse all C source files (*.c) in the given directory and extract TyPro facts.
        
        Args:
            source_dir (str): The directory containing C source files.
        
        Returns:
            List[Fact]: A list of extracted Fact objects.

    def _get_or_create_type_context(self, type_str: str, context: str) -> int:
        """
        Obtain a unique identifier for a given (type, context) pair.
        If not already present, create a new TypeContextPair fact.
        
        Args:
            type_str (str): The canonical type string.
            context (str): The context where the type is used (e.g., function name or global).
        
        Returns:
            int: The unique identifier for the (type, context) pair.

            return self.type_context_map[key]

        unique_id: int = self.next_id

        self.next_id += 1

        fact: Fact = Fact(fact_id=unique_id, fact_type="TypeContextPair", data=fact_data)

    def _is_indirect_call(self, cursor: Cursor) -> bool:
        """
        Determine if a call expression is an indirect call.
        An indirect call is assumed when the callee does not directly refer to a function declaration.
        
        Args:
            cursor (Cursor): The CallExpr cursor.
        
        Returns:
            bool: True if the call is indirect, False if direct.
        """
        # Recursively check if any child eventually is a direct function reference.
        def contains_function_decl(c: Cursor) -> bool:
            if c.kind == CursorKind.DECL_REF_EXPR and c.referenced is not None and c.referenced.kind == CursorKind.FUNCTION_DECL:
                return True
            for child in c.get_children():
                if contains_function_decl(child):
                    return True
            return False

        # For a call expression, check its callee.
        for child in cursor.get_children():
            if contains_function_decl(child):
                return False
        return True

    def _is_address_of_function(self, cursor: Cursor) -> bool:
        """
        Determine if a UnaryOperator cursor represents an address-of operator applied to a function.
        
        Args:
            cursor (Cursor): The UnaryOperator cursor.
        
        Returns:
            bool: True if the operator is an address-of operator for a function, False otherwise.
        """
        # Check tokens for the '&' operator.
        tokens = list(cursor.get_tokens())
        if any(token.spelling == "&" for token in tokens):
            # Check if any child references a FUNCTION_DECL
            for child in cursor.get_children():
                if child.kind == CursorKind.DECL_REF_EXPR and child.referenced is not None and child.referenced.kind == CursorKind.FUNCTION_DECL:
                    return True
        return False

    def _process_type(self, clang_type: cindex.Type, context: str) -> int:
        """
        Process a clang type by creating a TypeContextPair fact for it.
        Also handle pointer types and record PointsTo facts, as well as record
        struct/union fields via StructMember/UnionMember facts.
        
        Args:
            clang_type (cindex.Type): The type to process.
            context (str): The context in which this type is used.
        
        Returns:
            int: The unique identifier for the processed type's TypeContextPair.
        """
        type_str: str = clang_type.spelling
        type_id: int = self._get_or_create_type_context(type_str, context)

        # Process pointer types: if the type is a pointer or array, process the pointee.
        if clang_type.kind == TypeKind.POINTER:
            pointee_type = clang_type.get_pointee()
            pointee_id = self._process_type(pointee_type, context)
            self._create_points_to_fact(type_id, pointee_id)

        # Process array types similarly.
        if clang_type.kind in (TypeKind.CONSTANTARRAY, TypeKind.INCOMPLETEARRAY):
            # For array types, process the element type.
            element_type = clang_type.get_array_element_type()
            if element_type is not None:
                element_id = self._process_type(element_type, context)
                self._create_points_to_fact(type_id, element_id)

        # Process record types (structs or unions).
        if clang_type.kind == TypeKind.RECORD:
            decl = clang_type.get_declaration()
            if decl is not None and decl.spelling:
                # Determine if it's a struct or union.
                if decl.kind == CursorKind.STRUCT_DECL:
                    parent_id = type_id
                    for child in decl.get_children():
                        if child.kind == CursorKind.FIELD_DECL:
                            field_type = child.type
                            field_str = field_type.spelling
                            # Use the parent's context as the field context.
                            member_id = self._get_or_create_type_context(field_str, context)
                            # Attempt to get offset; if not available, default to 0.
                            try:
                                offset = int(child.get_field_offset() // 8)
                            except Exception:
                                offset = 0
                            self._create_struct_member_fact(parent_id, member_id, offset)
                elif decl.kind == CursorKind.UNION_DECL:
                    parent_id = type_id
                    for child in decl.get_children():
                        if child.kind == CursorKind.FIELD_DECL:
                            field_type = child.type
                            field_str = field_type.spelling
                            member_id = self._get_or_create_type_context(field_str, context)
                            self._create_union_member_fact(parent_id, member_id, field_str)
        return type_id

    def _visit(self, cursor: Cursor, current_context: str) -> None:
        """
        Recursively visit the AST nodes starting at 'cursor', extract facts for each node,
        and update the analysis facts list. The current_context indicates the active scope,
        e.g., a function name or "global" for top-level declarations.

        Args:
            cursor (Cursor): The current AST node.
            current_context (str): The current context (function name or global).
        """
        # Update context if the current node is a function declaration.
        new_context: str = current_context
        if cursor.kind == CursorKind.FUNCTION_DECL:
            if cursor.spelling:
                new_context = cursor.spelling
                self.logger.debug(f"Entering function context: {new_context}")

                # Also record a TypeContextPair for the function declaration itself.
                self._process_type(cursor.type, new_context)

        # For variable declarations at global scope or within functions.
        if cursor.kind == CursorKind.VAR_DECL:
            # Use the current context; record the variable's type.
            self._process_type(cursor.type, new_context)

        # For declarations that are struct or union, process the type.
        if cursor.kind in (CursorKind.STRUCT_DECL, CursorKind.UNION_DECL):
            if cursor.spelling:  # Only process named records
                # Process the record type.
                record_type = cursor.type
                self._process_type(record_type, new_context)

        # For expressions: record a TypeContextPair for their type.
        # Some expressions may not have a valid type; so check.
        if cursor.kind.is_expression() and cursor.type.spelling:
            self._process_type(cursor.type, new_context)

        # Check for cast expressions (explicit cast or implicit cast).
        if cursor.kind in (CursorKind.CSTYLE_CAST_EXPR, CursorKind.IMPLICIT_CAST_EXPR):
            # For cast expressions, attempt to get the source expression (first child).
            children = list(cursor.get_children())
            if children:
                source_cursor = children[0]
                # Get unique ids for source and destination types.
                src_type_id = self._process_type(source_cursor.type, new_context)
                dst_type_id = self._process_type(cursor.type, new_context)
                self._create_cast_fact(src_type_id, dst_type_id)

        # Check for unary operator: address-of operator for function pointers.
        if cursor.kind == CursorKind.UNARY_OPERATOR:
            if self._is_address_of_function(cursor):
                # In an address-of operator applied to a function, get the child that is a DeclRefExpr.
                for child in cursor.get_children():
                    if child.kind == CursorKind.DECL_REF_EXPR and child.referenced is not None and child.referenced.kind == CursorKind.FUNCTION_DECL:
                        fdecl = child.referenced
                        func_name: str = fdecl.spelling
                        # Extract function type from the function declaration.
                        func_type = fdecl.type
                        # Process the function type to get its unique id.
                        self._process_type(func_type, new_context)
                        # Get function arity and vararg information.
                        arity: int = fdecl.type.argument_count if fdecl.type.argument_count is not None else 0
                        vararg: bool = fdecl.type.is_function_variadic()
                        self._create_function_pointer_fact(func_name, arity, vararg, func_type.spelling, new_context)

        # Check for call expressions.
        if cursor.kind == CursorKind.CALL_EXPR:
            # Determine if the call is indirect.
            if self._is_indirect_call(cursor):
                # Use the location of the call to form a unique call label.
                location = cursor.location
                if location.file:
                    call_label = f"{os.path.basename(location.file.name)}:{location.line}:{location.column}"
                else:
                    call_label = "unknown"
                # Process the callee expression type (first child if available).
                children = list(cursor.get_children())
                if children:
                    callee_cursor = children[0]
                    call_type_id = self._process_type(callee_cursor.type, new_context)
                else:
                    call_type_id = self._get_or_create_type_context("unknown", call_label)
                # Get the number of arguments using get_arguments()
                try:
                    arguments = list(cursor.get_arguments())
                    arity = len(arguments)
                except Exception:
                    arity = 0
                self._create_icall_fact(call_type_id, call_label, arity)
                # For each argument, record a TypeCall fact with the argument's type.
                try:
                    for arg in cursor.get_arguments():
                        arg_type_str = arg.type.spelling
                        self._create_typecall_fact(arg_type_str, call_label)
                except Exception:
                    pass
                # Optionally, record a TypeCall for the return type.
                ret_type_str = cursor.type.spelling
                if ret_type_str and ret_type_str != "void":
                    self._create_typecall_fact(ret_type_str, call_label)

        # Process pointer types for expressions (if node type is pointer or array, _process_type already handles PointsTo).
        if cursor.type.kind in (TypeKind.POINTER, TypeKind.CONSTANTARRAY, TypeKind.INCOMPLETEARRAY):
            self._process_type(cursor.type, new_context)

        # Recursively visit all child nodes.
        for child in cursor.get_children():
            self._visit(child, new_context)

"""
fact_optimizer.py

This module implements the FactOptimizer class which takes a list of Fact objects
(defined in utils.py) and applies several optimizations such as merging equivalent 
TypeContextPair facts, collapsing chains of Cast facts, removing duplicate facts, 
and pruning unused facts. The resulting optimized fact set is then used as input 
for the Soufflé Datalog solver in the TyPro pipeline.

The optimization process follows the guidelines in the TyPro paper and the provided design:
  1. Merging equivalent TypeContextPair facts via reciprocal Cast facts.
  2. Collapsing chains of Cast facts via transitive reduction.
  3. Removing duplicate facts (exact copies).
  4. Pruning facts that are not referenced by any other fact, except for root facts
     (e.g., FunctionPointer, ICall, TypeCall) or those marked for external use.
  5. Skipping primitive C types (smaller than pointer size) from TypeContextPair.

All configuration settings are read from the config.yaml file using parse_config in utils.py.
All logging is handled via the shared logging utility in utils.py, with strong type annotations everywhere.
"""

from typing import Any, Dict, List, Set, Tuple
import copy
import logging

from utils import Fact, parse_config, get_logger

# -----------------------------------------------------------------------------
# Disjoint Set Union (Union-Find) implementation for merging TypeContextPair facts.
# -----------------------------------------------------------------------------
class DSU:
    def __init__(self, elements: Set[int]) -> None:
        # Parent mapping for each element.
        self.parent: Dict[int, int] = {x: x for x in elements}

    def find(self, x: int) -> int:
        # Path compression.
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> None:
        # Union by choosing the smaller id as canonical
        root_x = self.find(x)
        root_y = self.find(y)
        if root_x == root_y:
            return
        if root_x < root_y:
            self.parent[root_y] = root_x
        else:
            self.parent[root_x] = root_y

    def _merge_type_context_pairs(self, facts: List[Fact]) -> Dict[int, int]:
        """
        Merge TypeContextPair facts that are reciprocally castable.
        
        Returns a mapping from each TypeContextPair fact id to its canonical representative id.
        """
        # Collect ids for TypeContextPair facts.
        tcp_ids: Set[int] = {fact.id for fact in facts if fact.fact_type == "TypeContextPair"}
        dsu = DSU(tcp_ids)

        # Build a set of cast edges where both src and dst are TypeContextPair.
        cast_edges: Set[Tuple[int, int]] = set()
        for fact in facts:
            if fact.fact_type == "Cast":
                src = fact.data.get("src")
                dst = fact.data.get("dst")
                if isinstance(src, int) and isinstance(dst, int) and src in tcp_ids and dst in tcp_ids:
                    cast_edges.add((src, dst))
        
        # For each cast edge, if the reciprocal cast exists, union the two.
        for (src, dst) in cast_edges:
            if (dst, src) in cast_edges:
                dsu.union(src, dst)

        # Build the merge map: each TypeContextPair id is mapped to its representative.
        merge_map: Dict[int, int] = {}
        for x in tcp_ids:
            rep = dsu.find(x)
            merge_map[x] = rep

        self.logger.debug("Merge map for TypeContextPair: %s", merge_map)
        return merge_map

    def _update_references(self, facts: List[Fact], mapping: Dict[int, int]) -> None:

        Args:
            facts (List[Fact]): The list of Fact objects.
            mapping (Dict[int, int]): Mapping from old fact ids to canonical ids.

        for fact in facts:
            for key, value in fact.data.items():

                    new_value = mapping[value]
                    if new_value != value:

                        fact.data[key] = new_value
                # If the value is a list of ints, update each element.
                if isinstance(value, list):
                    new_list = []
                    for item in value:
                        if isinstance(item, int) and item in mapping:
                            new_list.append(mapping[item])
                        else:
                            new_list.append(item)
                    fact.data[key] = new_list

    def _collapse_cast_chains(self, facts: List[Fact]) -> None:
        """
        Collapse chains of Cast facts via transitive reduction.
        For each Cast fact, if the same destination can be reached from the source
        via an alternative path (excluding that direct edge), mark it as redundant.
        Redundant Cast facts are removed from the list 'facts'.
        """
        # Build a cast graph: mapping src -> set of dst values (from Cast facts)
        cast_facts = [fact for fact in facts if fact.fact_type == "Cast"]
        graph: Dict[int, Set[int]] = {}
        fact_id_to_cast_fact: Dict[Tuple[int, int], Fact] = {}
        for fact in cast_facts:
            src = fact.data.get("src")
            dst = fact.data.get("dst")
            if isinstance(src, int) and isinstance(dst, int):
                graph.setdefault(src, set()).add(dst)
                fact_id_to_cast_fact[(src, dst)] = fact

        # Helper function: DFS from 'current' to find 'target', skipping a specific edge.
        def dfs(current: int, target: int, skip_edge: Tuple[int, int], visited: Set[int]) -> bool:
            if current == target:
                return True
            visited.add(current)
            for neighbor in graph.get(current, set()):
                # Skip the specific edge if encountered
                if (current, neighbor) == skip_edge:
                    continue
                if neighbor not in visited:
                    if dfs(neighbor, target, skip_edge, visited):
                        return True
            return False

        redundant_ids: Set[int] = set()
        # Evaluate each Cast fact edge for redundancy.
        for fact in cast_facts:
            src = fact.data.get("src")
            dst = fact.data.get("dst")
            if not (isinstance(src, int) and isinstance(dst, int)):
                continue
            # If there exists an alternate path from src to dst (excluding this edge), mark as redundant.
            if dfs(src, dst, (src, dst), set()):
                redundant_ids.add(fact.id)

        # Remove redundant Cast facts from the facts list.
        before = len(facts)
        facts[:] = [fact for fact in facts if not (fact.fact_type == "Cast" and fact.id in redundant_ids)]
        after = len(facts)
        self.logger.debug("Collapsed cast chains: Removed %d redundant Cast facts.", (before - after))

    def _remove_duplicates(self, facts: List[Fact]) -> Dict[int, int]:
        """
        Remove duplicate facts that have identical fact_type and identical data.
        Returns a mapping from duplicate fact ids to the canonical fact id.
        """
        seen: Dict[Tuple[str, Tuple[Tuple[str, Any], ...]], int] = {}
        duplicate_map: Dict[int, int] = {}  # Maps duplicate fact id to canonical fact id.
        for fact in facts:
            # Create a canonical representation: fact_type and sorted items from data.
            # Note: We ignore the 'id' field in the representation.
            data_items = tuple(sorted(fact.data.items()))
            key = (fact.fact_type, data_items)
            if key in seen:
                canonical_id = seen[key]
                duplicate_map[fact.id] = canonical_id
                self.logger.debug("Found duplicate fact: id %d is duplicate of id %d.", fact.id, canonical_id)
            else:
                seen[key] = fact.id
                duplicate_map[fact.id] = fact.id
        return duplicate_map

    def _prune_unused_facts(self, facts: List[Fact]) -> List[Fact]:
        """
        Prune facts that are not referenced by any other fact except for root facts or those
        marked for external use (via data 'external': True).
        Additionally, omit primitive C types from TypeContextPair facts.
        
        Returns:
            List[Fact]: The pruned list of facts.
        """
        reference_keys = {"src", "dst", "ptr", "pointee", "parent", "member", "callType"}
        used_ids: Set[int] = set()

        # Collect all referenced ids from fact data
        for fact in facts:
            for key, value in fact.data.items():
                if key in reference_keys:
                    if isinstance(value, int):
                        used_ids.add(value)
                    elif isinstance(value, list):
                        for item in value:
                            if isinstance(item, int):
                                used_ids.add(item)

        # Define root fact types that must always be kept.
        root_fact_types = {"FunctionPointer", "ICall", "TypeCall"}
        for fact in facts:
            if fact.fact_type in root_fact_types:
                used_ids.add(fact.id)

        pruned_facts: List[Fact] = []
        for fact in facts:
            # Always preserve external facts, if marked.
            if fact.data.get("external", False):
                pruned_facts.append(fact)
                continue
            # For TypeContextPair facts, also check if the type is a primitive that should be omitted.
            if fact.fact_type == "TypeContextPair" and self._is_primitive_to_prune(fact):
                self.logger.debug("Pruning TypeContextPair fact id %d with primitive type '%s'.", 
                                  fact.id, fact.data.get("type", ""))
                continue
            # Keep the fact if its id is used or if it is not a candidate for removal.
            if fact.id in used_ids or fact.fact_type in root_fact_types:
                pruned_facts.append(fact)
            else:
                self.logger.debug("Pruning unused fact id %d of type '%s'.", fact.id, fact.fact_type)
        return pruned_facts

    def _is_primitive_to_prune(self, fact: Fact) -> bool:
        """
        Determine whether a TypeContextPair fact represents a primitive C type that should be pruned.
        The method prunes types that do not contain pointer indicators ("*"), struct/union declarations,
        or function pointer markers ("fptr").
        
        Args:
            fact (Fact): A Fact object expected to be of type "TypeContextPair".
        
        Returns:
            bool: True if the fact represents a primitive type to be pruned; False otherwise.
        """
        if fact.fact_type != "TypeContextPair":
            return False
        type_str: str = str(fact.data.get("type", "")).lower().strip()
        # Allow if it is a pointer type, or a struct/union/function pointer.
        if "*" in type_str or "struct" in type_str or "union" in type_str or "fptr" in type_str:
            return False
        # Otherwise, if the type is a primitive type.
        primitive_types = {"void", "char", "short", "int", "long", "float", "double"}
        # Split the type string into words and check if all are in primitive_types.
        words = set(type_str.split())
        # If any word is in primitive_types, we choose to prune.
        if any(word in primitive_types for word in words):
            return True
        return False

datalog_solver.py

This module implements the DatalogSolver class for the TyPro pipeline.
It accepts an optimized list of Fact objects (from AST extraction and fact optimization),
converts them into CSV files (one per relation) expected by the Soufflé Datalog solver,

identifier (callLabel) to a list of allowed function identifiers for that call.

The class adheres to the design specification and uses configuration settings

import tempfile
import shutil
import logging
from typing import List, Dict

# Import shared utilities and Fact class from utils.py.
from utils import Fact, parse_config, get_logger

class DatalogSolver:
    """
    DatalogSolver bridges the fact-based analysis and enforcement by invoking the Soufflé Datalog solver.

    Attributes:
        rules_file (str): Path to the Soufflé rules file (default "rules.dl").
        souffle_path (str): Path to the Soufflé binary (default "souffle").
        config (Dict[str, any]): Configuration loaded from config.yaml.
        logger (logging.Logger): Logger instance.
    """

    def __init__(self, rules_file: str = "rules.dl", souffle_path: str = "souffle") -> None:
        """
        Initialize a DatalogSolver instance with the specified rules file and Soufflé binary path.
        
        Args:
            rules_file (str): Path to the Datalog rules file. Default is "rules.dl".
            souffle_path (str): Path to the Soufflé binary. Default is "souffle".
        """
        self.config: Dict[str, any] = parse_config("config.yaml")
        self.rules_file: str = rules_file
        self.souffle_path: str = souffle_path
        self.logger: logging.Logger = get_logger("DatalogSolver")
        self.logger.debug("DatalogSolver initialized with rules_file='%s' and souffle_path='%s'.",
                          self.rules_file, self.souffle_path)

    def solve(self, facts: List[Fact]) -> Dict[str, List[int]]:
        """
        Solve the Datalog analysis to compute the TargetSet mapping.

        The method performs the following steps:
          1. Groups the given Fact objects by fact_type and writes each group to a CSV file in a temporary facts directory.
          2. Invokes the Soufflé Datalog solver with the provided rules file, specifying the input facts directory and an output directory.
          3. Parses the output "TargetSet.csv" file generated by Soufflé to build a mapping where each indirect call (callLabel)
             is mapped to a list of allowed function identifiers (as integers).
          4. Cleans up the temporary directories before returning the mapping.

        Args:
            facts (List[Fact]): Optimized list of Fact objects.

        Returns:
            Dict[str, List[int]]: A dictionary mapping each indirect call identifier to a list of allowed function IDs.

        Raises:
            RuntimeError: If the Soufflé solver fails or if the required output file is missing.
        """
        # Create temporary directories for the facts input and solver output.
        facts_dir: str = tempfile.mkdtemp(prefix="souffle_facts_")
        output_dir: str = tempfile.mkdtemp(prefix="souffle_output_")
        self.logger.info("Created temporary facts directory: %s", facts_dir)
        self.logger.info("Created temporary output directory: %s", output_dir)

        try:
            # Step 1: Group facts by fact_type.
            grouped_facts: Dict[str, List[Fact]] = {}
            for fact in facts:
                grouped_facts.setdefault(fact.fact_type, []).append(fact)
            self.logger.info("Grouped facts by relation: %s", list(grouped_facts.keys()))

            # Write each group of facts to a corresponding CSV file.
            for fact_type, fact_list in grouped_facts.items():
                file_path: str = os.path.join(facts_dir, f"{fact_type}.csv")
                with open(file_path, "w", encoding="utf-8") as csv_file:
                    for fact in fact_list:
                        csv_line: str = self._format_fact_as_csv(fact)
                        csv_file.write(csv_line + "\n")
                self.logger.debug("Wrote %d facts to file '%s'.", len(fact_list), file_path)

            # Step 2: Invoke Soufflé via subprocess.
            # Command structure: souffle -F <facts_dir> -D <output_dir> <rules_file>
            cmd: List[str] = [self.souffle_path, "-F", facts_dir, "-D", output_dir, self.rules_file]
            self.logger.info("Invoking Soufflé with command: %s", " ".join(cmd))
            result = subprocess.run(cmd, capture_output=True, text=True)
            if result.returncode != 0:
                self.logger.error("Soufflé Datalog solver failed with exit code: %d", result.returncode)
                self.logger.error("Soufflé stderr: %s", result.stderr)
                raise RuntimeError("Soufflé Datalog solver execution failed.")
            self.logger.info("Soufflé Datalog solver completed successfully.")

            # Step 3: Parse the output file "TargetSet.csv".
            target_set_file: str = os.path.join(output_dir, "TargetSet.csv")
            if not os.path.exists(target_set_file):
                self.logger.error("Expected output file '%s' not found.", target_set_file)
                raise RuntimeError("Soufflé output missing TargetSet.csv file.")
            target_mapping: Dict[str, List[int]] = {}
            with open(target_set_file, "r", encoding="utf-8") as ts_file:
                for line in ts_file:
                    line = line.strip()
                    if not line:
                        continue
                    # Split the line by comma (CSV format, no header).
                    parts = line.split(",")
                    if len(parts) < 2:
                        self.logger.warning("Malformed line in TargetSet.csv: '%s'", line)
                        continue
                    call_id: str = parts[0].strip()
                    target_id_str: str = parts[1].strip()
                    try:
                        target_id: int = int(target_id_str)
                    except ValueError:
                        self.logger.warning("Non-integer function identifier '%s' in line: '%s'", target_id_str, line)
                        continue
                    if call_id not in target_mapping:
                        target_mapping[call_id] = []
                    target_mapping[call_id].append(target_id)
            self.logger.info("Parsed TargetSet mapping: %s", target_mapping)

            # Step 4: Return the computed mapping.
            return target_mapping

        finally:
            # Clean up temporary directories.
            try:
                shutil.rmtree(facts_dir)
                shutil.rmtree(output_dir)
                self.logger.debug("Cleaned up temporary directories.")
            except Exception as cleanup_error:
                self.logger.warning("Error during cleanup of temporary directories: %s", cleanup_error)

    def _format_fact_as_csv(self, fact: Fact) -> str:
        """
        Convert a Fact object into a CSV string suitable for Soufflé input.
        
        The CSV fields are ordered based on the fact_type as defined in the expected_fields mapping.
        If the fact_type is not recognized, the keys from fact.data are sorted alphabetically.

        Args:
            fact (Fact): The Fact object to format.
        
        Returns:
            str: A CSV-formatted string representing the fact.
        """
        expected_fields: Dict[str, List[str]] = {
            "TypeContextPair": ["id", "type", "context"],
            "PointsTo": ["ptr", "pointee"],
            "StructMember": ["parent", "member", "offset"],
            "UnionMember": ["parent", "member", "fieldType"],
            "Cast": ["src", "dst"],
            "ICall": ["callType", "callLabel", "arity"],
            "FunctionPointer": ["id", "func", "arity", "vararg"],
            "TypeCall": ["id", "type", "callLabel"]
        }
        field_order: List[str] = expected_fields.get(fact.fact_type)
        if field_order is None:
            field_order = sorted(fact.data.keys())
        values: List[str] = []
        for field in field_order:
            if field == "id" and fact.fact_type in {"TypeContextPair", "FunctionPointer", "TypeCall"}:
                value = fact.id
            else:
                value = fact.data.get(field)
            # Convert booleans to "true"/"false"
            if isinstance(value, bool):
                value_str = "true" if value else "false"
            elif isinstance(value, int):
                value_str = str(value)
            elif value is None:
                value_str = ""
            else:
                # Replace any commas in strings to avoid CSV conflicts.
                value_str = str(value).replace(",", ";")
            values.append(value_str)
        # Join the field values with commas.
        csv_line: str = ",".join(values)
        return csv_line

"""
code_transformer.py

This module implements the CodeTransformer class for the TyPro pipeline.
It reads an input LLVM IR (as a string), identifies indirect call instructions
(which are expected to be marked with a comment "typro_id:<call_id>"), and replaces
them with a switch-case construct that dispatches among allowed function targets
(as computed by the Datalog analysis and provided in the target_sets mapping).

The switch-case construct is implemented by generating specialized “dispatch”
functions (one per indirect call site) that implement a switch over the numeric
function identifiers. In the default branch the dispatch function calls an error
handler (__typro_fail) to immediately terminate the program.

This implementation uses a simple regex-based parsing strategy on the LLVM IR text.
It uses configuration from config.yaml and logging from utils.py.
"""

import re
import logging
from typing import Dict, List, Tuple
import os

from utils import parse_config, get_logger

class CodeTransformer:
    """
    CodeTransformer provides methods to transform LLVM IR by replacing indirect calls
    with equivalent switch-case constructs that enforce the forward CFI policy.

    Methods:
        transform(target_sets: Dict[str, List[int]]) -> str
           Reads the stored LLVM IR, replaces each indirect call (identified via a 
           marker "typro_id:<call_id>") with a call to a generated dispatch function,
           appends the dispatch function definitions to the IR, and returns the updated IR.
    """

    def __init__(self, llvm_ir: str) -> None:
        """
        Initialize the CodeTransformer with the given LLVM IR string.

        Args:
            llvm_ir (str): The full LLVM IR as a string.
        """
        self.llvm_ir: str = llvm_ir
        self.config: Dict[str, any] = parse_config("config.yaml")
        self.logger: logging.Logger = get_logger("CodeTransformer")
        self.logger.debug("Initialized CodeTransformer with LLVM IR input.")

    def transform(self, target_sets: Dict[str, List[int]]) -> str:
        """
        Transforms the LLVM IR by replacing indirect call instructions with switch-case
        constructs based on allowed function target sets. Indirect calls are identified
        by the presence of "typro_id:<call_id>" in a comment on the call instruction.
        
        The transformation process:
          1. Parses the IR line by line and identifies call instructions that are indirect
             (the callee operand starts with '%' instead of '@') and carries a marker.
          2. Replaces each such indirect call with a call to a generated dispatch function
             named __typro_dispatch_<call_id>. The dispatch function signature embeds
             the original function pointer operand and the original call arguments.
          3. For each transformed call, accumulates data required to generate a dispatch
             function definition that implements a switch-case over allowed function IDs.
          4. At the end, appends all dispatch function definitions to the IR.
          
        Args:
            target_sets (Dict[str, List[int]]): A mapping from indirect call identifiers
                (strings) to a list of allowed function target IDs (integers).
                
        Returns:
            str: The transformed LLVM IR as a string.
        """
        # Prepare to accumulate output lines and dispatch function information.
        output_lines: List[str] = []
        # dispatch_funcs maps call_id to a dictionary with keys:
        #   "ret_type": return type string
        #   "param_list": list of tuples (param_type, param_name) for original call args
        #   "original_line": the original call line (for debug reference)
        dispatch_funcs: Dict[str, Dict[str, any]] = {}

        # Regex pattern to detect an indirect call line.
        # It matches lines that start with optional whitespace, an optional result assignment,
        # then a call instruction with a return type, where the callee operand begins with '%' (indirect call),
        # and ending with a comment containing "typro_id:<call_id>".
        pattern = re.compile(
            r"^(?P<prefix>\s*)(?P<assignment>%\S+\s*=\s+)?call\s+(?P<ret_type>[\w\*\s]+)\s+(?P<callee>%\S+)\((?P<args>[^\)]*)\).*; *typro_id:(?P<call_id>\S+)"
        )

        # Process the LLVM IR line by line.
        for line in self.llvm_ir.splitlines():
            match = pattern.match(line)
            if match:
                prefix: str = match.group("prefix")
                assignment: str = match.group("assignment") or ""
                ret_type: str = match.group("ret_type").strip()
                callee: str = match.group("callee").strip()
                args_str: str = match.group("args").strip()
                call_id: str = match.group("call_id").strip()

                self.logger.debug("Found indirect call with call_id: %s", call_id)

                # Parse the original call argument list.
                # We assume the argument list is a comma-separated list of "TYPE VALUE" pairs.
                param_list: List[Tuple[str, str]] = []  # Each tuple: (param_type, param_name)
                arg_names: List[str] = []  # Parameter names to be used in the dispatch function call.
                if args_str:
                    args_parts = [arg.strip() for arg in args_str.split(",") if arg.strip()]
                    for i, arg in enumerate(args_parts):
                        # Attempt to split the argument into type and value.
                        arg_match = re.match(r"^(?P<type>\S+)(\s+(?P<val>.+))?$", arg)
                        if arg_match:
                            arg_type: str = arg_match.group("type").strip()
                            param_name: str = f"%a{i}"
                            param_list.append((arg_type, param_name))
                            arg_names.append(param_name)
                        else:
                            # If parsing fails, use the whole argument as type and generate a parameter name.
                            param_list.append((arg, f"%a{i}"))
                            arg_names.append(f"%a{i}")

                # Build new call instruction: replace the indirect call with a call to the dispatch function.
                # The first argument of the new dispatch function is the original callee operand (which now holds a function identifier),
                # followed by the original call arguments (now passed as parameters).
                dispatcher_func_name = f"__typro_dispatch_{call_id}"
                new_args = ", ".join([callee] + arg_names)
                new_call_line = f"{prefix}{assignment}call {ret_type} @{dispatcher_func_name}({new_args}) ; transformed indirect call"
                output_lines.append(new_call_line)

                # Record dispatch function information if not already recorded.
                if call_id not in dispatch_funcs:
                    dispatch_funcs[call_id] = {
                        "ret_type": ret_type,
                        "param_list": param_list,
                        "original_line": line
                    }
            else:
                # Unmodified line.
                output_lines.append(line)

        # Generate dispatch function definitions.
        dispatch_defs: List[str] = []
        for call_id, info in dispatch_funcs.items():
            # Get allowed targets from target_sets; if missing, warn and use an empty list.
            if call_id not in target_sets:
                self.logger.warning("No target set found for call_id '%s'. Defaulting to empty target set.", call_id)
                allowed_targets: List[int] = []
            else:
                allowed_targets = target_sets[call_id]
            # Order allowed targets in ascending order.
            allowed_targets_sorted = sorted(allowed_targets)

            ret_type: str = info["ret_type"]
            param_list: List[Tuple[str, str]] = info["param_list"]
            # The dispatch function signature: first parameter is "i64 %fn_id" (the function identifier)
            # followed by the parameters extracted from the original call.
            param_str_items: List[str] = ["i64 %fn_id"]
            for (ptype, pname) in param_list:
                param_str_items.append(f"{ptype} {pname}")
            param_str: str = ", ".join(param_str_items)

            # Begin constructing the function definition.
            func_lines: List[str] = []
            func_lines.append(f"define {ret_type} @__typro_dispatch_{call_id}({param_str}) {{")
            func_lines.append("entry:")
            # Create the switch instruction using %fn_id.
            func_lines.append(f"  switch i64 %fn_id, label %typro_default_{call_id} [")
            for target_id in allowed_targets_sorted:
                func_lines.append(f"    i64 {target_id}, label %typro_case_{call_id}_{target_id}")
            func_lines.append("  ]")

            # Generate code for each allowed target case.
            for target_id in allowed_targets_sorted:
                func_lines.append(f"typro_case_{call_id}_{target_id}:")
                # Assume that the direct function corresponding to an allowed target is named "f<target_id>"
                if ret_type == "void":
                    func_lines.append(f"  call void @f{target_id}({', '.join(pname for (_, pname) in param_list)})")
                    func_lines.append(f"  br label %typro_continue_{call_id}")
                else:
                    func_lines.append(f"  %case_result = call {ret_type} @f{target_id}({', '.join(pname for (_, pname) in param_list)})")
                    func_lines.append(f"  br label %typro_continue_{call_id}")

            # Default case: call the error handler and mark unreachable.
            func_lines.append(f"typro_default_{call_id}:")
            func_lines.append("  call void @__typro_fail()")
            func_lines.append("  unreachable")

            # Continue block: return the result if non-void; otherwise, return void.
            func_lines.append(f"typro_continue_{call_id}:")
            if ret_type == "void":
                func_lines.append("  ret void")
            else:
                func_lines.append(f"  ret {ret_type} %case_result")
            func_lines.append("}")

            # Append the function definition.
            dispatch_defs.append("\n".join(func_lines))
            self.logger.debug("Generated dispatch function for call_id '%s':\n%s", call_id, "\n".join(func_lines))

        # Append the dispatch function definitions at the end of the IR.
        output_lines.append("")
        output_lines.append("; Begin TyPro dispatch function definitions")
        output_lines.extend(dispatch_defs)
        output_lines.append("; End TyPro dispatch function definitions")

        transformed_ir: str = "\n".join(output_lines)
        self.logger.info("Transformation complete. Generated dispatch functions for %d indirect calls.", len(dispatch_funcs))
        return transformed_ir


# For standalone testing, run this module directly.
if __name__ == "__main__":
    # Setup basic logging.
    logging.basicConfig(level=logging.DEBUG, format="%(asctime)s - %(name)s - %(levelname)s - %(message)s")
    
    # Sample LLVM IR input (a simplified example).
    sample_ir = """

entry:
  %1 = call i32 %ptr_func(i32 10) ; typro_id:call1
  ret i32 %1
}

declare i32 @f10(i32)
declare i32 @f20(i32)
"""
    # Example target_sets mapping.
    # In a real scenario, target_sets is produced by the DatalogSolver.
    example_target_sets = {
        "call1": [10, 20]
    }
    
    transformer = CodeTransformer(sample_ir)
    transformed_ir = transformer.transform(example_target_sets)
    print(transformed_ir)

"""evaluation.py

This module implements the Evaluator class, which sets up and runs a suite of benchmarks
to evaluate the TyPro-protected binaries against baseline (unprotected) binaries.
It measures correctness, security (average target set size), performance overhead,
binary size overhead, and optionally dynamic linking update times.

The Evaluator uses configuration settings from config.yaml via utils.parse_config,
and it relies on standard Python modules and utilities defined in utils.py.
All methods use strong type annotations and default values where appropriate.

Author: TyPro Evaluation Module
"""

import os
import sys
import json
import time
import statistics
import subprocess
import logging
from typing import Any, Dict, List, Optional

from utils import parse_config, get_logger

# -----------------------------------------------------------------------------
# Evaluator class definition
# -----------------------------------------------------------------------------
class Evaluator:
    """
    Evaluator class sets up and runs benchmarks for evaluating the TyPro pipeline.
    
    It measures:
        - Correctness: comparing output between baseline (unprotected)
          and protected binaries.
        - Security: computes the average number of allowed targets per indirect call
          from the TargetSet mapping.
        - Performance Overhead: measures average runtime (plus standard deviation)
          over multiple runs.
        - Binary Size Overhead: compares file sizes between baseline and protected binaries.
        - If dynamic linking is enabled, measures additional time for dynamic module update.
    
    Methods:
        __init__(benchmark_config: dict) -> None
        run_benchmarks() -> Dict[str, Any]
            Runs all benchmarks and returns a dictionary containing evaluation metrics.
    """

    def __init__(self, benchmark_config: Optional[Dict[str, Any]] = None) -> None:
        """
        Initialize the Evaluator with configuration data.
        
        Args:
            benchmark_config (Optional[Dict[str, Any]]): Benchmark configuration.
                If not provided, the configuration loaded from config.yaml is used.
                Expected keys include "benchmarks" (a list of benchmark names) and "metrics".
        """
        self.config: Dict[str, Any] = parse_config("config.yaml")
        # Load the evaluation section from configuration; if benchmark_config provided, override.
        self.benchmark_config: Dict[str, Any] = benchmark_config if benchmark_config is not None else self.config.get("evaluation", {})
        # List of benchmark names; using default list if not specified.
        self.benchmarks: List[str] = self.benchmark_config.get("benchmarks", [
            "SPEC CPU 2006", "Apache", "lighttpd", "nginx", "pureftpd", "vsftpd", "memcached", "redis"
        ])
        # Default number of runs for performance measurement.
        self.num_runs: int = 10
        self.logger: logging.Logger = get_logger("Evaluator")
        self.logger.debug("Evaluator initialized with benchmarks: %s", self.benchmarks)

    def run_benchmarks(self) -> Dict[str, Any]:
        """
        Run the evaluation benchmarks and collect metrics on correctness,
        target set sizes, performance overhead, binary size overhead, and dynamic linking (if enabled).
        
        Returns:
            Dict[str, Any]: Dictionary aggregating the benchmark results.
                Format:
                  {
                    "correctness": {benchmark: True/False or error message},
                    "target_set": {benchmark: average_target_set_size (float)},
                    "performance": { benchmark: { "baseline_runtime": value,
                                                  "protected_runtime": value,
                                                  "overhead(%)": value,
                                                  "std_dev_baseline": value,
                                                  "std_dev_protected": value } },
                    "binary_size": { benchmark: { "baseline_size": value,
                                                  "protected_size": value,
                                                  "overhead(%)": value } },
                    "dynamic_linking": { benchmark: { "module_update_time": value } }  // Only if dynamic linking enabled
                  }
        """
        results: Dict[str, Any] = {
            "correctness": {},
            "target_set": {},
            "performance": {},
            "binary_size": {}
        }
        # If runtime dynamic linking is enabled in configuration, add that category.
        if self.config.get("runtime", {}).get("dynamic_linking", False):
            results["dynamic_linking"] = {}

        # Iterate over all benchmarks defined in the configuration.
        for benchmark in self.benchmarks:
            self.logger.info("Running benchmark: %s", benchmark)

            # Define binary paths.
            # For this implementation, we assume a directory structure:
            #   benchmarks/<benchmark>/baseline/<benchmark>
            #   benchmarks/<benchmark>/typro/<benchmark>_typro
            baseline_binary: str = os.path.join("benchmarks", benchmark, "baseline", benchmark)
            protected_binary: str = os.path.join("benchmarks", benchmark, "typro", benchmark + "_typro")

            # Check that binaries exist.
            if not os.path.exists(baseline_binary):
                error_msg = f"Baseline binary for benchmark '{benchmark}' not found at '{baseline_binary}'."
                self.logger.error(error_msg)
                results["correctness"][benchmark] = error_msg
                continue
            if not os.path.exists(protected_binary):
                error_msg = f"Protected binary for benchmark '{benchmark}' not found at '{protected_binary}'."
                self.logger.error(error_msg)
                results["correctness"][benchmark] = error_msg
                continue

            # -------------------------
            # Correctness Evaluation
            # -------------------------
            baseline_output: str = self._run_binary(baseline_binary, benchmark, mode="baseline")
            protected_output: str = self._run_binary(protected_binary, benchmark, mode="protected")
            is_correct: bool = (baseline_output == protected_output)
            results["correctness"][benchmark] = is_correct
            if not is_correct:
                self.logger.error("Output mismatch for benchmark '%s'.", benchmark)
            else:
                self.logger.info("Benchmark '%s' passed correctness check.", benchmark)

            # -------------------------
            # Performance Evaluation
            # -------------------------
            baseline_times: List[float] = self._time_runs(baseline_binary)
            protected_times: List[float] = self._time_runs(protected_binary)
            try:
                avg_baseline: float = statistics.mean(baseline_times)
            except statistics.StatisticsError:
                avg_baseline = 0.0
            try:
                std_baseline: float = statistics.stdev(baseline_times) if len(baseline_times) > 1 else 0.0
            except statistics.StatisticsError:
                std_baseline = 0.0
            try:
                avg_protected: float = statistics.mean(protected_times)
            except statistics.StatisticsError:
                avg_protected = 0.0
            try:
                std_protected: float = statistics.stdev(protected_times) if len(protected_times) > 1 else 0.0
            except statistics.StatisticsError:
                std_protected = 0.0
            overhead_percent: float = ((avg_protected - avg_baseline) / avg_baseline * 100.0) if avg_baseline > 0 else 0.0

            results["performance"][benchmark] = {
                "baseline_runtime": avg_baseline,
                "protected_runtime": avg_protected,
                "overhead(%)": overhead_percent,
                "std_dev_baseline": std_baseline,
                "std_dev_protected": std_protected
            }
            self.logger.info("Benchmark '%s' performance: baseline=%.4fs, protected=%.4fs (overhead=%.2f%%).",
                             benchmark, avg_baseline, avg_protected, overhead_percent)

            # -------------------------
            # Binary Size Evaluation
            # -------------------------
            try:
                baseline_size: int = os.path.getsize(baseline_binary)
                protected_size: int = os.path.getsize(protected_binary)
                size_overhead_percent: float = ((protected_size - baseline_size) / baseline_size * 100.0) if baseline_size > 0 else 0.0
            except Exception as size_error:
                self.logger.error("Error measuring binary size for benchmark '%s': %s", benchmark, size_error)
                baseline_size = 0
                protected_size = 0
                size_overhead_percent = 0.0

            results["binary_size"][benchmark] = {
                "baseline_size": baseline_size,
                "protected_size": protected_size,
                "overhead(%)": size_overhead_percent
            }
            self.logger.info("Benchmark '%s' binary sizes: baseline=%d bytes, protected=%d bytes (overhead=%.2f%%).",
                             benchmark, baseline_size, protected_size, size_overhead_percent)

            # -------------------------
            # Security (Target Set) Evaluation
            # -------------------------
            # Assume the TyPro pipeline outputs a JSON file named "target_set.json"
            # in the protected binary's directory.
            target_set_path: str = os.path.join("benchmarks", benchmark, "typro", "target_set.json")
            avg_target_set_size: float = 0.0
            if os.path.exists(target_set_path):
                try:
                    with open(target_set_path, "r", encoding="utf-8") as ts_file:
                        target_set_mapping: Dict[str, Any] = json.load(ts_file)
                        total_targets: int = 0
                        count_calls: int = 0
                        for call_id, targets in target_set_mapping.items():
                            if isinstance(targets, list):
                                total_targets += len(targets)
                                count_calls += 1
                        if count_calls > 0:
                            avg_target_set_size = total_targets / count_calls
                except Exception as ts_error:
                    self.logger.error("Error reading TargetSet mapping for benchmark '%s': %s", benchmark, ts_error)
            else:
                self.logger.warning("TargetSet mapping file not found for benchmark '%s' at '%s'.", benchmark, target_set_path)

            results["target_set"][benchmark] = avg_target_set_size
            self.logger.info("Benchmark '%s' average target set size: %.2f.", benchmark, avg_target_set_size)

            # -------------------------
            # Dynamic Linking Evaluation (if enabled)
            # -------------------------
            if self.config.get("runtime", {}).get("dynamic_linking", False):
                # For dynamic linking evaluation, assume that the protected binary can be invoked
                # with an extra argument "--dynamic-test" to simulate module loading and runtime updates.
                dynamic_times: List[float] = self._time_runs(protected_binary, extra_args=["--dynamic-test"], runs=5)
                try:
                    avg_dynamic: float = statistics.mean(dynamic_times)
                except statistics.StatisticsError:
                    avg_dynamic = 0.0
                results["dynamic_linking"][benchmark] = {
                    "module_update_time": avg_dynamic
                }
                self.logger.info("Benchmark '%s' dynamic linking module update time: %.4fs.", benchmark, avg_dynamic)

        return results

    def _run_binary(self, binary_path: str, benchmark: str, mode: str) -> str:
        """
        Run the given binary once and capture its output.
        
        Args:
            binary_path (str): Path to the executable binary.
            benchmark (str): Benchmark name (for logging).
            mode (str): Either "baseline" or "protected".
        
        Returns:
            str: The standard output produced by the binary, or an empty string if an error occurs.
        """
        try:
            proc = subprocess.run([binary_path], capture_output=True, text=True, timeout=120)
            output: str = proc.stdout.strip()
            self.logger.debug("%s run output for benchmark '%s': %s", mode.capitalize(), benchmark, output)
            return output
        except subprocess.TimeoutExpired:
            self.logger.error("%s run of benchmark '%s' timed out.", mode.capitalize(), benchmark)
            return "timeout"
        except Exception as e:
            self.logger.error("Error running %s binary for benchmark '%s': %s", mode, benchmark, e)
            return ""

    def _time_runs(self, binary_path: str, extra_args: Optional[List[str]] = None, runs: Optional[int] = None) -> List[float]:
        """
        Execute the binary multiple times and record execution durations.
        
        Args:
            binary_path (str): Path to the executable.
            extra_args (Optional[List[str]]): Additional command line arguments for the run.
            runs (Optional[int]): Number of runs to execute; defaults to self.num_runs.
        
        Returns:
            List[float]: List of execution times in seconds.
        """
        run_times: List[float] = []
        num_runs: int = runs if runs is not None else self.num_runs
        for i in range(num_runs):
            try:
                args: List[str] = [binary_path]
                if extra_args is not None:
                    args.extend(extra_args)
                start_time: float = time.time()
                subprocess.run(args, capture_output=True, text=True, timeout=120)
                end_time: float = time.time()
                elapsed: float = end_time - start_time
                run_times.append(elapsed)
                self.logger.debug("Run %d for '%s' completed in %.4fs.", i + 1, binary_path, elapsed)
            except subprocess.TimeoutExpired:
                self.logger.error("Run %d for binary '%s' timed out.", i + 1, binary_path)
            except Exception as e:
                self.logger.error("Error during run %d for binary '%s': %s", i + 1, binary_path, e)
        return run_times

/*
 * runtime_enforcer.cpp
 *
 * This file implements the DynamicLinkerEnforcer class which provides dynamic
 * runtime enforcement for TyPro’s forward CFI scheme. It loads module summary
 * files, merges external facts with the static fact set, re-runs the target set
 * computation via an external (simulated) Soufflé invocation, and triggers just-in-time
 * (JIT) recompilation of switch-case trampolines for indirect calls.
 *
 * The implementation uses a dedicated, protected heap allocated via mmap to store
 * module summaries and JIT-generated code. Memory protection is enforced via mprotect.
 * All updates are performed atomically under a mutex.
 *
 * Configuration values are read from the configuration file "config.yaml" (if available)
 * but default values are always provided.
 *
 * Required Libraries/Headers:
 *  - Standard C++ libraries.
 *  - POSIX headers: <sys/mman.h>, <unistd.h>
 *  - A JSON parser header (nlohmann/json.hpp) is used to parse module summary files.
 *
 * Author: TyPro Runtime Enforcement Component
 */

#include <fstream>
#include <sstream>
#include <string>
#include <vector>

#include <set>

static const bool DEFAULT_DYNAMIC_LINKING = true;
static const size_t DEFAULT_PROTECTED_HEAP_SIZE = 1024 * 1024; // 1 MB
static const std::string DEFAULT_MODULE_SUMMARY_PATH = "module_summary.json";
static const std::string DEFAULT_TARGETSET_OUTPUT_PATH = "runtime_targetset_output.json";

// Utility function to load a configuration value from a YAML-like file.
// In this simplified implementation, we only check for the "runtime:" section and its key "dynamic_linking".
// For full YAML parsing a dedicated library would be used, but here we use default values.
static bool loadDynamicLinkingFlag(const std::string &configPath = "config.yaml") {
    std::ifstream configFile(configPath);
    if (!configFile.is_open()) {
        std::cerr << "[RuntimeEnforcer] Warning: Could not open config file '" << configPath 
                  << "'. Using default dynamic_linking flag: " << (DEFAULT_DYNAMIC_LINKING ? "true" : "false") << std::endl;
        return DEFAULT_DYNAMIC_LINKING;
    }
    std::string line;
    bool dynamicLinking = DEFAULT_DYNAMIC_LINKING;
    while (std::getline(configFile, line)) {
        std::istringstream iss(line);
        std::string key;
        if (line.find("dynamic_linking:") != std::string::npos) {
            size_t pos = line.find(":");
            std::string value = line.substr(pos + 1);
            // Remove whitespace
            value.erase(0, value.find_first_not_of(" \t"));
            if (value == "true") {
                dynamicLinking = true;
            } else if (value == "false") {
                dynamicLinking = false;
            }
            break;
        }
    }
    configFile.close();
    return dynamicLinking;
}

    void* protected_heap_;
    // Size of the protected heap.

    // Mutex to ensure atomic updates.
    std::mutex update_mutex_;
    // Merged external summary: a set of fact strings.
    std::set<std::string> merged_summary_;
    // Trampoline mapping: maps a call identifier (string) to an atomic pointer to its dispatch routine.
    std::map<std::string, std::atomic<void*>> trampoline_map_;

    // Allocate memory for the protected heap using mmap.
    void* allocate_protected_heap(size_t size);
    // Change memory protection of a region (e.g., to make it executable).
    void change_memory_protection(void* addr, size_t size, int prot);
    // Simulate target set computation by merging static and external facts.
    // In a full implementation, this would invoke Soufflé; here we simulate a dummy output.

void* DynamicLinkerEnforcer::allocate_protected_heap(size_t size) {

}

void DynamicLinkerEnforcer::jit_recompile_trampoline(const std::string & call_id, const std::vector<int>& allowed_targets) {
    /*
     * This function simulates the JIT recompilation of a trampoline switch-case construct.
     * Steps:
     *  1. Allocate a new executable code region (simulate with mmap).
     *  2. Write a dummy code pattern that encodes the allowed target identifiers.
     *  3. Verify the code written.
     *  4. Change memory protection to Read + Exec.
     *  5. Atomically update the trampoline pointer in trampoline_map_.
     */

    // For simulation, use a fixed code region size.
    const size_t code_size = 256;
    void* jit_code = mmap(NULL, code_size, PROT_READ | PROT_WRITE,
                          MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
    if (jit_code == MAP_FAILED) {
        log("JIT recompile failed: unable to allocate new code region.");
        return;
    }
    // Write a dummy pattern (for each allowed target, store its int value sequentially).
    memset(jit_code, 0, code_size);
    int* code_int_ptr = static_cast<int*>(jit_code);
    for (size_t i = 0; i < allowed_targets.size() && i * sizeof(int) < code_size; ++i) {
        code_int_ptr[i] = allowed_targets[i];
    }
    // Verification: Check that the written values match.
    bool verified = true;
    for (size_t i = 0; i < allowed_targets.size() && i * sizeof(int) < code_size; ++i) {
        if (code_int_ptr[i] != allowed_targets[i]) {
            verified = false;
            break;
        }
    }
    if (!verified) {
        munmap(jit_code, code_size);
        log("JIT recompile failed: verification error in generated code.");
        return;
    }
    // Change protection: mark the code region as read and executable (remove write permissions).
    try {
        change_memory_protection(jit_code, code_size, PROT_READ | PROT_EXEC);
    } catch (const std::runtime_error &e) {
        munmap(jit_code, code_size);
        log("JIT recompile failed: " + std::string(e.what()));
        return;
    }
    // Atomically update the trampoline pointer for call_id.
    {
        // No additional locking needed as we are under the update_mutex_ caller.
        if (trampoline_map_.find(call_id) == trampoline_map_.end()) {
            trampoline_map_[call_id] = jit_code;
        } else {
            trampoline_map_[call_id].store(jit_code);
        }
    }
    log("JIT recompiled trampoline for call_id '" + call_id +
        "'. Allowed targets count: " + std::to_string(allowed_targets.size()));
}

void DynamicLinkerEnforcer::update_target_sets(const json & module_summary) {
    /*
     * This function updates the runtime target sets when new module summaries are loaded.
     * Steps:
     *  1. Acquire a lock to ensure update atomicity.
     *  2. Validate the module summary format.
     *  3. Merge new facts into the master summary (merged_summary_).
     *  4. If new facts were added, combine with static facts (simulated here) and run
     *     target set computation.
     *  5. For each indirect call in the computed TargetSet mapping, trigger JIT recompilation.
     */
    std::lock_guard<std::mutex> lock(update_mutex_);
    log("update_target_sets: Starting update with new module summary.");

    // Validate that module_summary is expected to have a "facts" array.
    if (!module_summary.contains("facts") || !module_summary["facts"].is_array()) {
        log("Error: Module summary format invalid (missing 'facts' array). Terminating.");
        std::exit(EXIT_FAILURE);
    }
    bool new_fact_added = false;
    for (const auto &fact : module_summary["facts"]) {
        if (!fact.is_string())
            continue;
        std::string factStr = fact.get<std::string>();
        if (merged_summary_.find(factStr) == merged_summary_.end()) {
            merged_summary_.insert(factStr);
            new_fact_added = true;
            log("New fact merged: " + factStr);
        }
    }
    if (!new_fact_added) {
        log("No new facts merged. Target set update not required.");
        return;
    }
    // Combine merged_summary_ facts into a combined summary json object.
    json combined_summary;
    combined_summary["facts"] = json::array();
    for (const auto &factStr : merged_summary_) {
        combined_summary["facts"].push_back(factStr);
    }
    // Run target set computation (simulated here).
    json target_set_mapping = run_target_set_computation(combined_summary);
    // For each indirect call, trigger JIT recompilation of its trampoline.
    for (auto& [call_id, targetsJson] : target_set_mapping.items()) {
        if (!targetsJson.is_array())
            continue;
        std::vector<int> allowedTargets;
        for (const auto &val : targetsJson) {
            if (val.is_number_integer())
                allowedTargets.push_back(val.get<int>());
        }
        jit_recompile_trampoline(call_id, allowedTargets);
    }
    log("update_target_sets: Completed target set update.");
}

void DynamicLinkerEnforcer::log(const std::string & msg) {
    std::cerr << "[DynamicLinkerEnforcer] " << msg << std::endl;
}
