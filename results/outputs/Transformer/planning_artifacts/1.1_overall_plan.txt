1. OVERVIEW OF THE METHODOLOGY

• Model Architecture  
 – The Transformer uses a fully attention‐based encoder–decoder design.  
 – The encoder consists of N = 6 identical layers; each encoder layer is composed of:  
  ▸ A multi-head self-attention sub-layer.  
  ▸ A position-wise feed-forward network (two linear layers with a ReLU in between).  
  ▸ Each sub-layer uses residual (skip) connections followed by layer normalization.  
  ▸ The dimension used throughout is d_model = 512 for the base model.  
 – The decoder also comprises N = 6 identical layers and includes:  
  ▸ A self-attention sub-layer (with masking to prevent attending to subsequent positions).  
  ▸ A multi-head attention sub-layer over the encoder’s outputs (“encoder-decoder attention”).  
  ▸ A position-wise feed-forward sub-layer.  
  ▸ Similar residual connections and layer normalization as in the encoder.

• Attention Variants  
 – Scaled Dot-Product Attention:  
  ▸ Given queries Q and keys K (of dimension d_k), compute Q · K^T, scale by 1/√d_k and apply softmax.  
 – Multi-Head Attention:  
  ▸ Perform h = 8 parallel attention computations (for the base model), each with d_k = d_v = 64 (since 512/8 = 64).  
  ▸ Concatenate the outputs and project them back to a 512-dimensional space.

• Positional Encoding  
 – Since the model has no recurrence, add positional information through fixed sinusoidal encodings:  
  ▸ PE(pos, 2i) = sin(pos/10000^(2i/d_model))  
  ▸ PE(pos, 2i+1) = cos(pos/10000^(2i/d_model))  
 – (Optionally provide an implementation switch to experiment with learned positional embeddings.)

• Embeddings  
 – Convert input tokens to vectors using a learned embedding matrix, scaled by √d_model.  
 – Use the same weight matrix for the output projection (pre-softmax) to tie the embeddings.

2. DATA AND EXPERIMENTAL SETUP

A. Machine Translation Tasks  
 • Datasets  
  – WMT 2014 English–German: Approximately 4.5 million sentence pairs.  
  – WMT 2014 English–French: Approximately 36 million sentence pairs.  
 • Preprocessing  
  – Tokenize sentences and apply byte-pair encoding for English–German with a shared vocabulary of ~37,000 tokens.  
  – For English–French, use word-piece tokenization with a vocabulary of 32,000 tokens.  
 • Batching Strategy  
  – Batch examples together based on approximate sequence lengths so that each training batch has roughly 25,000 source tokens and 25,000 target tokens.

B. Constituency Parsing Task  
 • Dataset  
  – Use the WSJ portion of the Penn Treebank (approx. 40K sentences) for the WSJ-only setting.  
  – For semi-supervised experiments, also incorporate the larger high-confidence corpus (≈17M sentences).  
 • Vocabulary  
  – Use a 16K-token vocabulary for the WSJ-only setting and a 32K-token vocabulary for the semi-supervised setting.  
 • Model Adjustment  
  – Use a modified Transformer with 4 layers and an increased d_model = 1024.  
  – Adjust the beam search (see below) and dropout settings with minimal hyperparameter tuning using the designated development set.

3. TRAINING SETUP AND HYPERPARAMETERS

A. Optimizer and Learning Rate Schedule  
 • Optimizer: Use Adam with:  
  – β1 = 0.9  
  – β2 = 0.98  
  – ϵ = 10⁻⁹  
 • Learning Rate Schedule:  
  – Use the schedule defined by:  
   lr = d_model⁻⁰.⁵ * min(step⁻⁰.⁵, step * warmup_steps⁻1.5)  
  – Set warmup_steps = 4000.

B. Regularization  
 • Apply dropout at multiple points:  
  – Dropout (P_drop = 0.1 for the base model) after each sub-layer output (before adding the residual connection and layer normalization).  
  – Also apply dropout on the sum of embeddings and positional encodings.  
 • Label Smoothing  
  – Use a label smoothing value ϵ_ls = 0.1 during training. This helps improve BLEU scores (though it increases perplexity).

C. Model Configurations  
 • Base Model  
  – Layers: 6 in encoder and 6 in decoder.  
  – d_model = 512, d_ff (inner layer of feed-forward) = 2048.  
  – Attention: h = 8 heads, each with d_k = d_v = 64.  
  – Training: 100,000 steps (approximately 12 hours on 8 P100 GPUs).  
  – Checkpoint Averaging: Average the last 5 checkpoints (saved every 10 minutes) for final decoding.
 • Big Model (for translation)  
  – Configuration (from Table 3 bottom line): likely increase to d_model = 1024, d_ff = 4096, and number of heads h = 16.  
  – Training: 300,000 steps (3.5 days on 8 P100 GPUs).  
  – Note: For the English–French task, the big model is trained with dropout rate P_drop = 0.1 (instead of 0.3 as used in some settings).  
 • Constituency Parsing  
  – Use a 4-layer Transformer with d_model = 1024.  
  – Beam search for inference with beam size = 21 and length penalty α = 0.3.  
  – Increase maximum output length to input length + 300 tokens.  
  – Minimal hyperparameter tuning was done beyond the values derived from the translation task; only dropouts and learning rates were adjusted slightly on the development set.

D. Distributed Training and Hardware  
 • The original experiments were run on 8 NVIDIA P100 GPUs.  
 • Plan to implement data-parallel/distributed training for handling large batch sizes.  
 • If hardware is limited, note that timings and training cost (in terms of FLOPs) might vary.

4. EVALUATION AND INFERENCE

A. Translation Evaluation  
 • Use BLEU as the primary metric on standard test sets:  
  – For English–German, target BLEU ≈ 28.4 for the big model and ≈ 27.3 for the base model on the newstest2014.  
  – For English–French, target BLEU ≈ 41.8 for the big model.  
 • Inference Settings  
  – Use beam search with beam size = 4 and length penalty α = 0.6.  
  – Set maximum output sequence length to input length + 50 tokens, with early stopping if possible.

B. Constituency Parsing Evaluation  
 • Evaluate performance using F1 score on WSJ Section 23.  
 • For WSJ-only: expect F1 ≈ 91.3; for semi-supervised training: F1 in the range of 92.7–93.3.  
 • Use beam search with beam size = 21 and α = 0.3.

C. Checkpoint Averaging  
 • For better final results, average the model checkpoints as mentioned: last 5 for base models and last 20 for big models before decoding.

5. IMPLEMENTATION ROADMAP

Step 1. Data Preparation  
 – Write data loaders to read, tokenize, and batch the datasets.  
 – For translation, implement byte-pair encoding and batching by approximate token count.  
 – For parsing, prepare the WSJ data and any additional semi-supervised corpora (ensure correct tokenization and linearization of parse trees).

Step 2. Model Components  
 – Develop modules for:  
  • Scaled Dot-Product Attention (including handling of masks for decoder self-attention).  
  • Multi-Head Attention: perform h parallel projections, apply attention, concatenate, then project.  
  • Position-wise Feed-Forward Network (two linear layers with ReLU and dropout).  
  • Positional Encoding: fixed sine and cosine functions (with an option to switch to learned encodings).  
  • Embedding layers (with scaling) that also are tied with the output softmax weight.
 – Build the encoder and decoder blocks as described, ensuring each sub-layer has a residual connection and layer normalization.  
 – Assemble the overall encoder-decoder model.

Step 3. Training Loop  
 – Implement the optimizer (Adam) with the specified parameters and learning rate schedule.  
 – Incorporate dropout and label smoothing into the loss calculation.  
 – Incorporate distributed training if using multiple GPUs.  
 – Save checkpoints at fixed intervals (e.g., every 10 minutes of training iterations).

Step 4. Inference Module  
 – Implement beam search decoding that accepts parameters: beam size, length penalty, and maximum length (input length + offset).  
 – Ensure that in the decoder self-attention, a mask prevents a token from attending to future tokens.

Step 5. Logging and Evaluation  
 – Log training progress, validation loss, and intermediate BLEU scores on the development set (newstest2013 for translation).  
 – After training, apply checkpoint averaging, run beam search on the test set, and compute BLEU (for translation) or F1 (for parsing) scores.
