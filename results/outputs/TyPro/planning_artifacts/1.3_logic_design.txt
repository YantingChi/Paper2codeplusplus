[Logic Analysis]
- ['main.py', 'Main class: Orchestrates the complete pipeline. Imports ASTExtractor, FactOptimizer, DatalogSolver, CodeTransformer, DynamicLinkerEnforcer (optional), and Evaluator. Handles configuration and overall task flow.']
- ['ast_extractor.py', 'ASTExtractor class: Uses clang.cindex (libclang) to parse C source files and extract facts such as TypeContextPair, Cast, FunctionPointer, ICall, etc. Provides method extract_facts(source_dir: str) -> List<Fact>.']
- ['fact_optimizer.py', 'FactOptimizer class: Takes the list of extracted facts and performs optimization by merging redundant facts, collapsing cast chains, and pruning unused facts. Method optimize(facts: List<Fact]) -> List<Fact>.']
- ['datalog_solver.py', 'DatalogSolver class: Converts the optimized facts into the input format for Soufflé and executes the Datalog rules (from rules.dl) via a subprocess call. Returns the TargetSet mapping (indirect call identifier -> list of allowed function IDs). Method solve(facts: List<Fact]) -> Dict[str, List[int]].']
- ['code_transformer.py', 'CodeTransformer class: Reads LLVM IR (generated by LLVM/clang) and replaces indirect function call instructions with switch-case constructs based on the TargetSet mapping. Utilizes llvmlite for IR manipulation or shells out to LLVM tools. Method transform(llvm_ir: str, target_sets: Dict[str, List[int]]) -> str.']
- ['runtime_enforcer.cpp', "RuntimeEnforcer component (C++): Implements dynamic linking support by loading and merging module summaries, re-running target set computations on the fly, and triggering 'just-in-time' recompilation of switch-case constructs when new modules are loaded. Interacts with the protected binary at runtime."]
- ['evaluation.py', 'Evaluator class: Sets up experimental benchmarks (SPEC CPU 2006 and real-world applications) and runs performance, correctness, and security evaluations. Methods include run_benchmarks() -> dict, collecting metrics on runtime performance, binary size overhead, and target set sizes.']
- ['utils.py', 'Utility functions and common data structures, including the Fact class definition. Provides functions for configuration parsing, file I/O for fact files, and logging. This module is imported by multiple components.']
- ['rules.dl', 'Datalog rules file: Contains Horn clause rules for type propagation, cast transitivity, handling of pointers, structs, unions, and computing the TargetSet relation. This file is read by the DatalogSolver for analysis via Soufflé.']

[Shared Knowledge]
Common configuration and utility functions (in utils.py) are shared among modules. The Fact class (with attributes id, fact_type, and data) is used across AST extraction, optimization, and the Datalog solver. Configuration variables such as file paths, clang/LLVM settings, and Soufflé execution parameters should be centralized and documented. All modules rely on a consistent JSON or YAML format for passing fact data and target set mappings.
