[Implementation approach]
We will implement a modular pipeline that reproduces the paper’s TyPro method using open-source libraries. First, we use Python with clang’s libclang bindings to traverse the C source’s AST and extract type, context, cast, function pointer, and indirect call facts. These facts will be written to a structured file. Next, a fact optimizer module will merge and prune redundant facts. The optimized fact set is then passed to Soufflé (a Datalog solver) via an interfacing module that invokes Soufflé with the provided set of Horn-clause rules (implemented as a separate .dl file) to compute the TargetSet relation mapping each indirect call to its allowed function targets. Once the target sets are generated, a code transformation module (using llvmlite or an external LLVM pass) replaces indirect calls in the LLVM IR with equivalent switch-case constructs that directly invoke validated function identifiers. Finally, a runtime enforcer component (implemented in C++ and interfaced via Python if needed) supports dynamic linking by loading module summaries and updating the target sets at runtime. This simple architecture leverages clang-cindex, Soufflé, and llvmlite to maintain clarity and separation of concerns.

    end
    M->>EV: run_benchmarks()
