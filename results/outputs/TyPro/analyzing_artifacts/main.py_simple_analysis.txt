  – Pass the list of facts to the FactOptimizer.
  – The FactOptimizer prunes unused TypeContextPair facts, collapses chains of casts (e.g. converting "(fptr_int)((void*)&f1)" into a single cast fact), and merges reciprocal cast facts.
  – This step is critical to reduce the size of the fact base, which the datalog solver must process.
  – The optimized fact list is returned for analysis.

  – Instantiate the DatalogSolver with the provided Soufflé rules file (rules.dl) and the path to the Soufflé executable.

  – The result is a mapping (e.g., a dictionary) where each indirect call’s identifier is mapped to a list of allowed function identifiers.
  – This mapping, representing the set of allowed targets per indirect call, is returned.

  – Call the transform() method, passing in the IR and the computed TargetSet mapping.
  – The CodeTransformer’s job is to replace indirect call instructions with equivalent switch-case constructs (where each case represents a direct call to one function from the allowed set). This transformation uses llvmlite (as per the configuration) or invokes LLVM pass directly.
  – The output is a transformed LLVM IR, which will be compiled into a binary that enforces the forward CFI policy.
