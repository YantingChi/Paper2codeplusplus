[Implementation approach]
We will build a modular Python system that reproduces the BE-CBO method by separating concerns into benchmark definition, surrogate model training (using BoTorch’s GP for the objective and a PyTorch deep ensemble for constraint classification), acquisition optimization (using constrained EI via SciPy’s SLSQP with a pre-optimization step using Adam), and experiment orchestration. The system will leverage open-source libraries such as PyTorch for neural networks, BoTorch (and GPyTorch) for GP modeling and acquisition functions, and SciPy for constrained optimization. A main application module will configure the experiment (using a simple config file or dictionary), initialize the appropriate modules, and run the Bayesian optimization loop over the designated evaluation budget.

[Program call flow]
sequenceDiagram
    participant M as Main
    participant B as Benchmark
    participant GP as GPSurrogate
    participant DE as DeepEnsembleClassifier
    participant AO as AcquisitionOptimizer
    participant BT as BOTrainer
    participant E as Evaluation

    M->>B: Load problem configuration and initialize benchmark
    B-->>M: Provide objective and constraint functions
    M->>GP: Initialize GP surrogate with config
    M->>DE: Initialize deep ensemble classifier with config
    M->>AO: Initialize Acquisition Optimizer with config
    M->>BT: Create BOTrainer(B, GP, DE, AO, config)
    BT->>B: Get initial samples (using Sobol sequence)
    loop For each BO iteration
        BT->>GP: Update GP using collected feasible data
        BT->>DE: Train/update classifier with (x, binary feasibility) data
        BT->>AO: Optimize the acquisition function (EI) with dynamic bound (l(x)=0.5 - σ) constraint
        AO-->>BT: Return candidate point x
        BT->>B: Evaluate candidate x
        B-->>BT: Return objective value and feasibility flag
        BT: Log result and update dataset
    end
    BT->>E: Send final results for evaluation
    E->>E: Compute metrics (best objective, feasibility ratio, classification accuracy)
    E-->>M: Return evaluation metrics
    M->>M: Log results and display summary output
